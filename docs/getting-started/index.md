# Getting Started

Kiwi Network is built around one principle: expose as little as possible.

## Components

- **kiwi-master**: public entry point; runs WireGuard and network-side services.
- **kiwi-node**: private services; connects to the master via WireGuard.
- **kiwi-workstation**: desktop OS for users/operators.
