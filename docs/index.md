# Kiwi Network

Kiwi Network is an all-in-one, privacy-first setup for self-hosting your software infrastructure using open-source and Linux.

## What you get

- `kiwi-master`: the secure entry point (VPN + core network services)
- `kiwi-node`: local services (cloud sync, password vault, downloads, and more)
- `kiwi-workstation`: an easy workstation OS for daily use

## Core security idea

Only the WireGuard endpoint is exposed to the public Internet. Everything else is reachable **only via VPN** (or locally on a node).
